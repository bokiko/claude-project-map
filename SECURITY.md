# Security policy

## Supported versions

Security fixes go into the latest release only (see [CHANGELOG.md](CHANGELOG.md)). The version you have is in `.claude-plugin/plugin.json`.

## Reporting a vulnerability

Please report privately: open this repository's **Security** tab and choose **Report a vulnerability**. Do not file a public issue for a security problem.

Include the project-map version, your operating system, what you ran and what happened. The reply comes in the private report.
